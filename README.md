# Rice-Cammeo-and-Osmancik-Classification
Project Machine Learning menggunakan dataset Rice Cammeo and Osmancik untuk klasifikasi jenis beras berdasarkan karakteristik morfologi butiran. Proyek ini mencakup tahapan data loading, data cleaning, exploratory data analysis (EDA), data splitting, pemodelan, dan evaluasi model menggunakan Python untuk memahami klasifikasi data.
